This project is a UI prototype designed for a desktop maintenance tool based on ADB interface, aiming to provide virus scanning, system cleanup, and log management for mobile devices. The entire interface is presented in dark mode, emphasizing module usability, process consistency, and user feedback.

This prototype is designed using Pixso and is not yet developed, serving only as a visual interaction demonstration.

Connect to wireless ADB through QR code scanning (non-login), displaying device model, status, and port information.

## 💡 Design Notes

- Adopted sidebar modular layout with persistent navigation bar to improve task switching efficiency
- Each state node has feedback mechanisms (color + icon + text), enhancing operation confidence
- All module designs are adapted for Electron or WebView application embedding scenarios
- Icons, color schemes, and layout styles reference excellent security tools like Huorong, **simplified and lightweight while maintaining professionalism**
